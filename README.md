# GYM20 Student Registration\n\nPersian RTL, mobile-friendly registration interface.\n\n## Current state\nThis repository currently contains a **front-end prototype** (`index.html`). Visitors can enter details, select disciplines/class options, see a limited sample price calculation, accept sample rules, and preview an image locally.\n\n**It does not submit, persist, or upload personal information or photos.** Do not use it for real registrations until secure backend, admin authentication, database, private file storage, validated pricing, and privacy notice are configured.\n\n## Preview\nOpen `index.html` locally, or enable GitHub Pages in repository Settings → Pages and select `main` / root.\n\n## Planned stages\n1. Review the registration flow and Persian copy.\n2. Confirm the pricing matrix for age group, class type, and 8/10/12 sessions.\n3. Build secure admin authentication and management.\n4. Connect database and private photo storage.\n5. Configure publication and test the public URL.\n\n## Privacy\nNever commit student records, phone numbers, payment credentials, or uploaded images to this repository.\n
